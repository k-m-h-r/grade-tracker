# ⚔️ GradeQuest（グレードクエスト）
**日々のテスト結果を記録・分析し、次の目標達成までの戦略を立てる成績管理Webアプリ**

定期考査や模試の点数を記録するだけで、成績の推移グラフや教科バランスを自動で可視化！
RPGのように教科ごとのレベルやランクが上がる仕組みで、毎日の勉強のモチベーションを高めます。

---

## ✨ このアプリでできること

### 1. 📊 ダッシュボード（成績の見える化 ＆ RPGステータス）
* **成績推移 ＆ 目標ライン**：テストごとの平均点・合計点の変化と、目標点までの距離をグラフで確認できます。
* **教科バランス比較**：最新テストと前回テストの得意・不得意をレーダーチャートで重ねて比較できます。
* **RPGレベル ＆ ランク判定**：テスト結果や勉強時間に応じて経験値が貯まり、総合ランク（S〜D）や教科別のマスタリーレベルがアップします。
* **🏆 リザルトカード生成**：各テストの「🏆 カード」ボタンから、戦績をまとめたカッコいい画像（PNG）を作成して保存・シェアできます。

### 2. ⚡ 成績入力（ストレスゼロの爆速記録）
* **ワンタップ・テンプレート**：「主要5教科」「定期考査 9教科」「理系重点」などのセットから入力欄をすぐに呼び出せます。
* **連続入力対応**：点数を入力して `Enter` キー（または改行キー）を押すと、自動で次の教科の点数欄へ移動します。
* **🩺 失点カルテ**：「計算ミス」「時間不足」「暗記抜け」などの失点理由をタップで手軽に記録できます。

### 3. 🎯 分析・逆算（次のテストに向けた戦略室）
* **目標逆算 ＆ 傾斜配点シミュレーター**：「次のテストで平均85点を取りたい」「数学と英語の配点が高い」といった条件に合わせて、各教科あと何点伸ばせば目標に届くかをシミュレーションできます。
* **弱点 ＆ 勉強効率の分析**：失点原因の割合（円グラフ）や、勉強時間と点数の関係（散布図）から、次に改善すべきポイントが見つかります。

## 🚀 はじめての使い方

1. **まずは動きを試してみる**
   * 初期状態ではサンプルデータが2件入っています。グラフやシミュレーターを自由に触って使い心地を試してみてください。
2. **自分の成績を入力する**
   * 上部の **「⚡ 成績入力」** タブを開き、テスト名・実施日・各教科の点数を入力して **「✅ この成績を保存する」** を押します。
   * サンプルデータが不要になったら、ダッシュボード下部の履歴一覧から「削除」できます。

---

## 💡 便利な機能

* **👁️‍🗨️ 隠す（プライバシー保護モード）**
  * 電車の中や学校で画面を開くとき、ヘッダーの **「👁️‍🗨️ 隠す」** ボタンを押すと具体的な点数や平均点にぼかしがかかり、周囲から点数を覗き見されるのを防ぎます。
* **🌓 テーマ切替**
  * 夜間の勉強でも目が疲れにくいダークモードと、明るいライトモードをワンタップで切り替えられます。

---

## 🔒 データの保存とバックアップについて（重要）

* **プライバシー安心設計**
  * 入力した成績データは外部サーバーには一切送信されず、**お使いのスマホ・iPad・PCのブラウザ内（localStorage）にのみ自動保存**されます。他の人に成績を見られることはありません。
* **定期的なバックアップのお願い**
  * ブラウザの履歴・キャッシュ削除を行った場合や、機種変更をした場合はデータが消えてしまいます。
  * 大切な記録を守るため、定期的に画面右上の **「💾 保存」** ボタンからバックアップファイル（`.json`）を端末に保存してください。
  * 別の端末へデータを移したいときは、**「📂 読込」** ボタンから保存したファイルを選ぶだけで復元できます。

---

## 📱 対応環境・注意事項
* スマートフォン、iPad（タブレット）、PCの各種ブラウザ（Safari / Chrome / Edge など）に対応しています。
* iPadやスマホのブラウザメニューから **「ホーム画面に追加」** を行うと、アプリのように全画面で素早く起動できます。
* グラフの表示にはインターネット接続が必要です。
