# GradeQuest - 成績記録＆戦略ダッシュボード

GitHub Pages（無料プラン）でそのまま公開できる、サーバーレス・静的Webの成績記録アプリです。

## 主な機能
1. **ハイブリッド保存方式**: ブラウザの `localStorage` に自動保存しつつ、ヘッダーの「💾 保存」「📂 読込」からいつでもJSONファイルでバックアップ・復元可能。
2. **ダッシュボード＆RPGステータス**: 平均点推移・目標ライン・教科バランスレーダーチャート・教科別レベル＆ランク判定（S〜D）を表示。
3. **爆速成績入力**: テンプレート切替、`Enter`キーによる連続フォーカス移動、失点原因カルテ（チップ選択）を搭載。
4. **分析・目標逆算シミュレーター**: 傾斜配点倍率を設定し、次回テストで各教科何点伸ばせば目標平均に届くかを逆算。失点原因円グラフと勉強時間相関図も搭載。
5. **リザルトカード生成＆プライバシー保護**: テスト結果をPNG画像として書き出し可能。ヘッダーの「👁️‍🗨️ 隠す」ボタンで具体的な点数にぼかしをかけられます。

## iPadでの作業＆GitHub Pages公開手順
1. ダウンロードした `grade-tracker.zip` をiPadの「ファイル」アプリでタップして解凍します。
2. コードを編集したい場合は、App Storeの無料エディタ（**Kodex** や **Runestone** など）や **GitHub Codespaces** でフォルダを開いて編集できます。
3. GitHubのiOSアプリまたはSafariから新しいリポジトリ（Public）を作成し、`index.html`・`css`・`js` フォルダをアップロードします。
4. リポジトリの **Settings > Pages** から Branch を `main` に設定して保存すると、数分で公開URLが発行されます。
