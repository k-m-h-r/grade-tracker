# GradeQuest - 成績記録＆戦略ダッシュボード

テストの点数・テスト平均点との差・学習時間・失点原因をまとめて記録し、次のテストに向けた戦略を立てられる成績管理Webアプリです。

## 主な機能

1. **ダッシュボード＆RPGステータス**
   - 最新の平均点・前回比・**テスト平均との差**をひと目で確認できます。
   - 成績の推移や勉強時間に応じてプレイヤーレベルや教科別レベルがアップし、成績に応じたランク（S〜D）が判定されます。
2. **成績推移＆教科バランスグラフ**
   - 自分の点数・**テスト平均点**・目標ラインを重ねて推移を比較できます。
   - レーダーチャートで「最新の自分」「テスト平均」「前回の自分」の教科バランスを可視化します。
3. **教科ごとの成績推移＆学習時間グラフ**
   - 「全教科比較」で全科目の推移を重ねて見比べられるほか、英語・数学・物理など**教科ごとの専用グラフ**に切り替えて「自分の得点推移」「その教科の平均点」「目標ライン」「学習時間(h)」をまとめて分析できます。
4. **爆速成績入力＆失点カルテ**
   - テンプレート（主要5教科 / 9教科 / 理系重点）からワンタップで入力欄を準備でき、`Enter`キーで次の点数欄へ連続移動できます。
   - テスト全体の平均点、または教科ごとの平均点を入力すると、自分との点差を自動計算します（未入力でも記録できます）。
   - 「計算ミス」「時間不足」などの失点原因をチップ選択で記録し、弱点の内訳を分析できます。
5. **目標逆算＆傾斜配点シミュレーター**
   - 目標平均点や志望校の配点倍率に合わせて、「次のテストで各教科あと何点伸ばせば届くか」をシミュレーションできます。
6. **リザルトカード生成＆プライバシー保護**
   - テスト結果を画像（PNG）として保存できます。
   - 電車や学校など周囲の目が気になる場所では、ヘッダーの「👁️‍🗨️ 隠す」ボタンで自分の点数にぼかしをかけられます。

## データの保存とバックアップについて（重要）

* **自動保存とプライバシー**：入力した成績データはすべてお使いの端末（ブラウザ内）に自動保存され、外部サーバーには送信されません。
* **定期的なバックアップのお願い**：ブラウザの履歴・キャッシュを削除した場合や、端末を機種変更した場合にはデータが消えてしまいます。大切な記録を守るため、画面上部の **「💾 保存」** ボタンから定期的にバックアップファイル（JSON）を保存し、復元したいときは **「📂 読込」** から読み込んでください。
